# Security Policy

## Scope

13Recon is intended for authorized defensive security research, lab environments, and bug-bounty programs that explicitly permit the activity.

## Reporting a vulnerability in 13Recon

Please open a private security report through the repository's GitHub Security features rather than publishing sensitive details in a public issue.

## Responsible use

Do not use 13Recon to access, scan, or disrupt systems without explicit authorization.
